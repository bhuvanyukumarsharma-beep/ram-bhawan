Ram Bhawan setup helper

This page does the fiddly typing for you, so you only copy and paste. Everything happens inside this page, on your own computer. Nothing you type here is sent anywhere.

A. Your Supabase details

From your Supabase project (guide, Step 1): the Project URL, and the publishable key. Never the "secret" key.

B. Email sending (recommended)

A Gmail address that will send the emails, and its 16-letter app password (guide, Step 2). Leave both empty to skip emails and use phone alerts only.

C. Your own login for the app (you are the owner)

1Secrets for Supabase

Goes in Supabase → Edge Functions → Secrets (guide, Step 6). Press Copy all lines, then paste into the first box. If Supabase puts everything into one box, use the little table below instead: one Copy button for each name and each value.

Table with one Copy button per item

2Your owner command

Paste into Supabase → SQL Editor and press Run (guide, Step 4, after the database is built).

3Schedule command

Paste into Supabase → SQL Editor and press Run (guide, Step 7).

4Your website file

This is the whole app, already connected to your database. You upload it to Netlify (guide, Step 8). Do not open the zip file. Just drag it as it is.

5Keep a private copy of everything

YOUR-SECRETS.txt holds your passwords. Keep it private, like a bank PIN: do not email it and do not share it. If you close this page before saving it, you will have to make new keys, and then repeat Steps 6, 7 and 8.
